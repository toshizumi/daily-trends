# 今日のトレンド

日本で話題になっていることを、毎朝1回まとめて表示するページです。

公開ページ: https://toshizumi.github.io/daily-trends/

## 表示している内容

いま話題になっていることとして、Google トレンドの急上昇ワード、X のトレンド、はてなブックマークの人気エントリーを出しています。X のトレンドは公式 API が有料なので、[trends24.in](https://trends24.in/japan/) が1時間ごとに記録している一覧を24時間分集め、トレンド入りしていた時間の長い順に並べています。

ここ数か月の流れとして、7日・30日・90日の期間ごとに次の2つを出しています。

1. Google と X のトレンドに何日登場したか。毎日の記録から数えるので、記録を始めた 2026年10月12日以降の分だけが対象です。
2. Wikipedia 日本語版で期間中によく読まれた記事と、直近7日で急に読まれ始めた記事。Wikimedia の API から過去分もさかのぼって取っています。

数十年単位の流れとして、次の2つをグラフにしています。

1. 内閣府「国民生活に関する世論調査」から、いまの生活への満足度、心の豊かさと物の豊かさのどちらを重んじるか、これからの生活の見通しの3つ。1960〜70年代から最新年までです。
2. 総務省統計局「家計調査」から、二人以上の世帯の品目別の年間支出。2000年から最新年までです。

博報堂生活総研の「生活定点」も同じ種類の長期調査ですが、利用規約で私的利用以外の利用とスクレイピングが禁止されているため、このページには取り込んでいません。

## 仕組み

GitHub Actions が毎朝6時（日本時間）に `scripts/collect.py` を動かし、結果を `docs/data/` にコミットします。ページは GitHub Pages で `docs/` をそのまま公開しています。サーバーもデータベースも使っていません。

```
docs/data/daily/YYYY-MM-DD.json  その日の Google・X・はてブの取得結果
docs/data/wiki/YYYY-MM-DD.json   Wikipedia 日本語版のその日の閲覧数上位100記事
docs/data/latest.json            画面が読む集計結果
docs/data/longterm.json          数十年単位の流れ（scripts/longterm.py が作る）
sources/cao/                     内閣府の世論調査の CSV（手で置いたもの）
```

家計調査は e-Stat から毎月1日に取り直します。内閣府の世論調査のサイトはブラウザ以外からの取得を受け付けないので、毎年秋に新しい調査結果が出たら、報告書ページの時系列 CSV（満足度、心の豊かさ、生活の見通し）を `sources/cao/report_*.csv` に置き換えてから `python3 scripts/longterm.py` を動かしてください。家計調査の年次表は改定のたびに新しいファイルが増えるので、`scripts/longterm.py` の `KAKEI_DETAIL` に ID を足す必要があります。

## 手元で動かす

Python 3.10 以上があれば、追加のライブラリなしで動きます。

```bash
python3 scripts/collect.py
python3 -m http.server 8765 --directory docs
```

Wikipedia の過去分を取り直すときは `--backfill-wiki 90` を付けます。

## 注意

GitHub Actions の定時実行は、混雑していると数十分遅れることがあります。取得元のどれかが失敗しても、残りの取得元の結果は表示し、失敗したことをそのカードに表示します。
